### Added

- Initial release: financial products for an amount or a cart and the best possible offer.
- Loan applications with order signing headers, simulation, status read and cancellation.
- Status notification route (PUT and POST) with CR-Signature verification, optional IP allow list,
  deduplication and order events.
- Product page widget configuration and snippet, paywall authentication key.
- Product types, widget types, creditors, account activation and widget key.
- Named connections, runtime connections and the `comfino:status` command.
